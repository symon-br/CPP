{
   VARIABLES:
   int -> stores integers values (whole number without decimal points).
   Eg. int A = 1;

   double -> stores the floating values (whole numbers with decimal points).
   Eg. double myFloatNum = 1.99;

   char -> stores single characters like 'a', 'B'. Char values are surrounded by single quotes.
   Eg. char myLetter = 'D';

   string -> stores full name or word like "Hello", "meow". Sting values are surrounded by double quotes.
   Eg. string myText = "Fuck";
   But to use string we must declear it in header like : #include <string>

   bool - stores values with two states: true or false.
   Eg. bool myBoolean = true;

   SYNTAX: 
   type variableName = value;
}
{
    if you dont want to write the datatype then simply use 'auto' keyword. This will automatically determines the datatype. 

    FOR EXAMPLE:
    // Creating auto variables
        auto myNum = 5; // int
        auto myFloatNum = 5.99f; // float
        auto myDoubleNum = 9.98; // double
        auto myLetter = 'D'; // char
        auto myBoolean = true; // bool
        auto myString = string("Hello"); // std::string
}

[
    The general rules for naming variables are:

    1. Names can contain letters, digits and underscores
    2. Names must begin with a letter or an underscore (_)
    3. Names are case-sensitive (myVar and myvar are different variables)
    4. Names cannot contain whitespaces or special characters like !, #, %, etc.
    5. Reserved words (like C++ keywords, such as int) cannot be used as names
]

{
    + operator is used differently on string, that is -> concatenation. 
    like:
    string firstName = "BRANDON";
    string lastName = "KARMA";
    string fullName = firstName + " " + lastName;
    cout << fullName;

    OUTPUT: BRANDON KARMA

    And also use append () function for this like:
    string firstName = "BRANDON ";
    string lastName = "KARMA";
    string fullName = firstName.append(lastName);
    cout << fullName;

    OUTPUT: BRANDON KARMA
}
